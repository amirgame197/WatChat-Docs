The app comes with a pretty robust theme editor that saves and loads the theme config from `localStorage`, fully in browser.

In the theme editor page, you can either create your own theme by changing the values and seeing what happens, or importing an *existing* theme JSON (supports <u>url-encoded</u> inputs too).

![](/img/theme-editor-page-image.png)

### For example, you can preview my [Red-Accent Theme](https://watchat.c0s.me/theme?theme=%7B%22version%22%3A2%2C%22background%22%3A%7B%7D%2C%22modes%22%3A%7B%22dark%22%3A%7B%22shared%22%3A%7B%22--accent-primary%22%3A%22%23ae1919%22%2C%22--toast-background%22%3A%22%23441d1d%22%7D%2C%22chat%22%3A%7B%22--accent-primary-faded%22%3A%22%23ae1919%22%2C%22--accent-hover%22%3A%22%23e51515%22%7D%2C%22index%22%3A%7B%7D%7D%2C%22light%22%3A%7B%22shared%22%3A%7B%22--accent-primary%22%3A%22%23ee4444%22%2C%22--toast-background%22%3A%22%23ecdfdf%22%7D%2C%22chat%22%3A%7B%22--accent-primary-faded%22%3A%22%23ae1919%22%2C%22--accent-hover%22%3A%22%23e51515%22%7D%2C%22index%22%3A%7B%7D%7D%7D%7D) and save it to use it everywhere! You can then press `Reset Saved Theme` to reset the app's theme back to the Default Blue.
