## Account
You don't need to create an account at all, all you have to do is to set a name and *preferably* an account profile picture. 

If you don't do that, a random name and profile picture will be automatically set for you.

## Main page

![](/img/main-page-image.png)

You can type an *arbitrary* room name and press `Continue`, that will send you directly to the room.

If there is an **existing** room with that name, you will enter that room. But if it's a **new** room, it will be automatically created.

> [!NOTE]
> Room names are currently limited to `AZaz09` characters.
>
> That means a room's name can only contain alphabetic characters, both <u>uppercase</u> and <u>lowercase</u> + all 10 digits.
